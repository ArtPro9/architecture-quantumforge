# HTML to Clean Text Processor

Этот скрипт очищает HTML файлы фандом-вики, заменяет ключевые термины и сохраняет тексты в `.txt` файлы.

## Структура проекта

```
knowledge_base/
├─ process_html.py        # основной скрипт
├─ terms_map.json         # словарь замен (original -> fictional)
├─ originals/             # папка с HTML файлами
└─ prepared/              # результат (очищенные .txt файлы)
```

## Использование

1. Поместите скачанные HTML файлы в папку `originals/`.
    - Каждый файл должен быть одной сущностью (персонаж, объект, событие).
2. Настройте `terms_map.json` с заменами ключевых терминов:

```json
{
  "Eren Yeager": "Arin Kael",
  "Titan": "Coloss",
  "Attack on Titan": "Citadel of the Colossi"
}
```

3. Запустите скрипт:

```bash
python process_html.py
```

4. После выполнения все обработанные тексты появятся в папке `prepared/` в формате `.txt`.

## Особенности

- Убираются скрипты, стили, таблицы, сноски и изображения.
- Сохраняется основной текст с разделением на абзацы.
- Происходит замена всех терминов из `terms_map.json`.
- Генерируется один `.txt` файл на один HTML файл.

## Советы

- Проверяйте результаты на корректность после первой обработки.
- Можно расширять словарь `terms_map.json` для полной замены всех узнаваемых терминов.
